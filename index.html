Import styles

Drop the Style Master (.csv or .xlsx) here, or The Style Master: Style # (A), Color (B), Status (C), Available date (D), Season (F), Description (J), Memo (K), Received qty (R). Category isn't in it, so styles keep theirs. Rows without a Style # are skipped. Nothing is saved until you confirm.

Import Production Sheet

Drop the production sheet (.xlsx) here, or Every tab is read. Columns are found by their headings — STYLE #, PO#, COLOR and TOP 1 … IN DATE (H, I, J and Z if not). A date in the TOP column marks that Style # + Color as TOP; a blank changes nothing. Nothing is saved until you confirm.
